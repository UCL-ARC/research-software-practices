# Go

Golang code should use the language's built-in formatting and auditing tools:

- [`go fmt`](https://pkg.go.dev/cmd/gofmt)
- [`go vet`](https://pkg.go.dev/cmd/vet)
- [`go fix`](https://pkg.go.dev/cmd/fix)

and follow the [Google style guide](https://google.github.io/styleguide/go/) which builds on [Effective Go](https://go.dev/doc/effective_go).

We usually adhere to the [golang-standards/project-layout](https://github.com/golang-standards/project-layout) to help readers navigate the project codebase.

For open-source projects, we recommend checking the [Go report card](https://goreportcard.com/).
